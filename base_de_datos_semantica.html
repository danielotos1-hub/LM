Comceptos y Tipos

Base de datos relacionales

Una base de datos relacional (RDBMS) es un sistema que organiza y administra los datos en tablas bidimensionales estructuradas. Estas tablas permiten almacenar y relacionar la información de forma lógica y eficiente.

Base de datos no relacionales

Una base de datos no relacional (NoSQL) es un sistema de almacenamiento diseñado para gestionar datos no estructurados o semiestructurados. A diferencia de los sistemas tradicionales, no utiliza la rigidez de las tablas basadas en filas y columnas, lo que le permite ofrecer una gran flexibilidad y una alta escalabilidad horizontal para manejar grandes volúmenes de información dinámica.

Estructura de una Base de Datos Relacional

  • Tablas (Entidades): Estructuras donde se organizan los datos.

  • Campos (Atributos): Columnas que definen la tipología de información.

  • Registros (Tuplas): Filas que contienen cada instancia concreta de datos.

  • Claves primarias (Primary Keys): Identificadores únicos de cada registro.

Las Relaciones en RDBMS

Las Cardinales Fundamentales

  • Relación 1:1 (Uno a Uno) :(ocurre cuando un registro de una tabla se asocia exclusivamente con un único registro de otra tabla, y viceversa.)

  • Relación 1:N (Uno a Muchos) :(ocurre cuando un registro de una tabla principal puede asociarse con varios registros de otra tabla secundaria, pero cada registro de la tabla secundaria pertenece a un único registro de la tabla principal)

  • Relación N:M (Muchos a muchos):ocurre cuando múltiples registros de una tabla pueden asociarse con múltiples registros de otra tabla.

  • Foreign key:Campo que une dos tablas en una relacion.
